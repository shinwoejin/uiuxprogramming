# Re:hear - 발표 훈련 설정

## 사용자와 목표
- 사용자: 발표를 준비하는 사람
- 목표: 훈련 조건을 정하고, 설정한 내용을 확인한다.

## 사용자의 흐름
1. 녹음 활용에 동의하고 '훈련 설정 시작하기'를 누른다.
2. 발표 제목을 입력한다. 비어 있으면 같은 단계에서 안내를 받는다.
3. 발표 시간을 선택하고 필요하면 질의 응답을 포함한다.
4. 제목, 시간, 질의응답 설정을 확인하고 수정하거나 완료한다.
5. 설정 완료 안내를 확인하고, 필요하면 다시 설정한다.

## 인터랙션 시나리오
1. 시작과 녹음 활용 안내
- 행동, 이벤트: 기존 동의 체크박스를 선택하고 '훈련 설정 시작하기'를 클릭한다.
- 조건: 녹음 활용 동의가 선택되었는가?
- 반응, 다음 상태: 동의 전에는 버튼을 누를 수 없다. 동의 후 클릭하면 사용 목적을 설명하는 안내 팝업이 열린다.
                팝업에서 '돌아가기'를 누르거나 ESC를 누르면 동의를 해제하고 시작 화면에 남는다.
                '동의하고 설정 시작하기'를 누르면 제목 입력 화면을 연다.
2. 제목 입력
- 행동, 이벤트: 제목을 적고 '훈련 조건 선택하기'를 클릭한다.
- 조건: 앞뒤 공백을 지운 제목이 비어 있는가?
- 반응, 다음 상태: 비어있으면 같은 화면에 오류를 표시하고 입력창에 초점을 둔다.
                값이 있으면 저장하고 조건 선택으로 이동한다.
3. 조건 선택
- 행동, 이벤트: 발표 시간을 바꾸거나 질의응답을 선택하고 '내용 확인하기'를 클릭한다.
- 조건: 질의응답을 선택했는가?
- 반응, 다음 상태: 선택했을 때만 질문 수를 보여준다.
4. 내용 확인
- 행동, 이벤트: 제목, 시간, 질의응답 내용을 읽고 '수정하기' 또는 '설정 완료하기'를 클릭한다.
- 조건: 수정인가, 완료인가?
- 반응, 다음 상태: 수정하면 입력한 값을 유지하고 조건 선택으로 돌아간다.
                완료하면 완료 안내로 이동한다.
5. 완료와 다시 설정
- 행동, 이벤트: 완료 안내를 읽고 필요하면 '다시 설정하기'를 클릭한다.
- 반응, 다음 상태: 새 설정의 제목, 시간, 질의응답, 진행 상태를 초기화하고 제목 입력부터 다시 시작한다.
                이미 확인한 녹음 활용 동의와 다른 기능을 유지한다.

# 추가 구현 - 돌발 상황 카드 뽑기
설정 완료 화면에 돌발 상황 카드 뽑기 기능을 추가했다. 7주차에 선택한 질의응답 여부와 발표 시간이 카드에 반영된다.

## 인터랙션 시나리오
- 행동: 설정 완료 화면에서 '돌발 상황 뽑기'를 클릭한다.
- 조건1: 질의응답을 포함했는가? 포함하면 선택한 질문 수만큼 질문 카드가 추가된다(5~8장).
- 조건2: 남은 카드가 있는가?
- 성공 반응: 남은 카드 중 1장을 무작위로 보여주고 덱에서 뺀다. 남은 카드 수와 버튼 문구가 바뀐다.
- 결과 없음: 카드를 모두 뽑고 '연습 마치기'를 누르면 "모든 돌발 상황을 연습했어요!" 안내가 나온다.
- 다음 행동: '처음부터 다시 뽑기'로 카드를 초기화한다. '다시 설정하기'로 조건을 바꾸면 다음 완료 때 바뀐 조건으로 카드가 새로 만들어진다.

## 테스트 결과
- 정상: 질의응답 없이 완료 후 뽑기 → 5장 중 1장씩 나오고 같은 카드가 반복되지 않음
- 조건 반영: 질의응답 3개, 10분으로 완료 → 전체 8장, "발표 시간이 10분에서 9분으로 줄었어요" 카드 확인
- 결과 없음: 카드를 모두 뽑고 '연습 마치기' → 완료 안내와 '처음부터 다시 뽑기' 버튼 표시
- 모바일: 좁은 화면에서 동의 체크박스 문구가 세로로 깨지는 문제를 발견해 수정함
